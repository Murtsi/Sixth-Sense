# Submission checklist

- [ ] Track: Meta — AI Glasses for Everyone, Everyday.
- [ ] Functional prototype and presentation deck.
- [ ] Audience and first-person wearable advantage demonstrated.
- [ ] Permissions, errors, performance, connectivity and device-state changes shown.
- [ ] Accessible onboarding, input/output and recovery tested.
- [ ] Consent, local/cloud processing and recording/deletion rules explained.
- [ ] Live glasses, phone camera and replay labelled separately.
- [ ] Measurements reproducible; unverified claims removed.
- [ ] Controlled demo and backup video ready; no reliance on prototype mobility guidance.
- [ ] Plausible adoption/pilot path; no invented partnership or user-study result.
- [ ] No identifying recordings, consent forms, tokens or restricted SDK assets in public Git/history.
- [ ] License explicitly selected by the owner.
- [ ] Public source/demo links, deck format and official deadline verified.
