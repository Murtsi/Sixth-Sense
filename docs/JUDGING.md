# Judging evidence

All criteria currently await implementation evidence.

| Weight | Criterion | Evidence to collect |
|---|---|---|
| 25% | Creativity and use case | A focused everyday problem, intended user and first-person hands-free benefit |
| 25% | Technical execution | Actual device path, permissions, failures, state changes, measured latency and performance trade-offs |
| 25% | Real-world value and feasibility | User feedback with consent, realistic hardware limits, adoption/pilot hypothesis and honest results |
| 25% | UX, accessibility and trust | Accessible onboarding/input/output, uncertainty, privacy controls and unavailable-state recovery |

Report live glasses, phone-camera and replay results separately. Latency targets and dataset plans are not achieved metrics. Confirm a pilot relationship before naming it as a partnership. Never equate a small demo with proven mobility safety.
